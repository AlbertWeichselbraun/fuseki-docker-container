# Fuseki Docker Container

Docker container and datasets used in the `Semantic Technologies` and `Knowledge Engineering and Extraction` lectures.
- The build is done via GitHub actions. 
- You can start the image with 
  ```bash
  docker pull ghcr.io/albertweichselbraun/jena-fuseki:latest
  docker run --network=host ghcr.io/albertweichselbraun/jena-fuseki:latest
  ```
